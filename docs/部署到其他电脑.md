# 部署到其他电脑教程

本文说明如何在**另一台 Windows 电脑**上部署「串口 Hub + Codex MCP」，使：

- 网页可常驻监控、发送  
- Codex 通过 MCP 读写**同一串口**与**同一日志**  
- 不出现双进程抢 COM  

Linux / macOS 步骤类似，路径与开机启动方式不同，文末有简要说明。

---

## 0. 目标机要求

| 项目 | 要求 |
|------|------|
| 系统 | Windows 10/11（推荐） |
| Python | 3.10+（安装时勾选 Add to PATH） |
| 串口 | 本机真实 COM 或虚拟串口对 |
| 可选 | [uv](https://docs.astral.sh/uv/)（更快装依赖） |
| 网络 | 默认仅本机 `127.0.0.1`；远程访问见第 6 节 |

---

## 1. 拷贝项目

任选一种：

**A. Git**

```powershell
cd F:\AI
git clone <你的仓库地址> umeko_serial_mcp
cd umeko_serial_mcp
```

**B. 压缩包**

把整个 `umeko_serial_mcp` 文件夹拷到目标机，例如：

```text
D:\tools\umeko_serial_mcp
```

建议路径**尽量避免**过度怪异的权限目录；中文路径一般可用，但若遇编码问题可改用纯英文路径如 `D:\serial_mcp`。

---

## 2. 创建虚拟环境并安装

在项目根目录：

```powershell
cd D:\tools\umeko_serial_mcp

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install -e .
```

检查：

```powershell
.\.venv\Scripts\start-serial-hub.exe --help
.\.venv\Scripts\python.exe -m umeko_serial_mcp --help
```

应能看到 `--hub` 等参数。`start-serial-hub` 无 --help 时直接运行会启动服务，可用 Ctrl+C 结束。

---

## 3. 启动 Hub（必做）

```powershell
.\scripts\start-hub.bat
```

或：

```powershell
.\.venv\Scripts\python.exe -m umeko_serial_mcp --hub --host 127.0.0.1 --http-port 8080
```

浏览器访问：

```text
http://127.0.0.1:8080
```

健康检查：

```powershell
Invoke-RestMethod http://127.0.0.1:8080/api/health
```

返回 `"ok": true` 即成功。

**保持该窗口运行**，不要关闭。网页长连依赖此进程。

---

## 4. 配置本机 Codex

编辑用户目录下配置（注意改成**目标机真实路径**）：

```text
C:\Users\<用户名>\.codex\config.toml
```

```toml
[mcp_servers.serial-mcp]
command = 'D:\tools\umeko_serial_mcp\.venv\Scripts\start-serial-mcp.exe'

[mcp_servers.serial-mcp.env]
SERIAL_MCP_HUB = "http://127.0.0.1:8080"
```

要点：

1. `command` 指向目标机上的 **`start-serial-mcp.exe`（瘦客户端）**  
2. **不要**把 `command` 配成 `--hub`（Hub 应单独常驻）  
3. `SERIAL_MCP_HUB` 指向本机 Hub  

重启 Codex，在对话中执行：

```text
用 serial-mcp 的 hub_status
```

应显示 `connected=...` 且无 “无法连接 Serial Hub”。

---

## 5. 开机自启 Hub（可选，推荐）

登录后自动起网页服务：

```powershell
cd D:\tools\umeko_serial_mcp
powershell -ExecutionPolicy Bypass -File .\scripts\install-hub-autostart.ps1
```

取消：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-hub-autostart.ps1 -Remove
```

自启后请确认 8080 未被其它程序占用。

---

## 6. 局域网其它设备访问网页（可选）

默认只监听 `127.0.0.1`（安全）。若要手机/其它 PC 看监控：

### 6.1 启动时监听所有网卡

```powershell
set SERIAL_MCP_HOST=0.0.0.0
.\scripts\start-hub.bat
```

或：

```powershell
.\.venv\Scripts\python.exe -m umeko_serial_mcp --hub --host 0.0.0.0 --http-port 8080
```

### 6.2 防火墙放行

以管理员 PowerShell：

```powershell
New-NetFirewallRule -DisplayName "Serial Hub HTTP" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow
New-NetFirewallRule -DisplayName "Serial Hub WS"   -Direction Inbound -Protocol TCP -LocalPort 8081 -Action Allow
```

### 6.3 访问地址

```text
http://<Hub电脑的局域网IP>:8080
```

### 6.4 远程 Codex 注意

- **串口只能由插着设备的那台电脑打开**  
- Codex 若在另一台机器，需让 MCP 进程跑在**有串口的机器**上，或使用远程桌面在串口机上跑 Codex  
- 不建议把 Hub 裸奔在公网  

若 Codex 与 Hub 同机，始终用：

```toml
SERIAL_MCP_HUB = "http://127.0.0.1:8080"
```

---

## 7. 与 XCOM / 其它串口工具共存

同一物理 COM **不能**被两个程序同时打开。

| 场景 | 建议 |
|------|------|
| 仅 Hub + Codex | 网页/MCP 都连同一 COM，例如 COM1 |
| 还要 XCOM 对测 | 使用虚拟串口对：Hub 连 COM2，XCOM 连 COM1 |
| 迁移电脑后 COM 号变了 | 网页「刷新串口」重新选 |

## 8. 升级代码

在项目目录：

```powershell
git pull
.\.venv\Scripts\python.exe -m pip install -e .
```

然后：

1. **重启 Hub**（Ctrl+C 再 `start-hub.bat`）  
2. **重启 Codex**（刷新 MCP 子进程）  

---

## 9. 卸载 / 清理

1. 取消开机启动（若装过）  
2. 结束 Hub 进程  
3. 删除项目目录与 `.venv`  
4. 从 `config.toml` 去掉 `serial-mcp` 段  

---

## 10. Linux / macOS 简要

```bash
cd /path/to/umeko_serial_mcp
python3 -m venv .venv
.venv/bin/pip install -e .

# 启动 Hub
.venv/bin/python -m umeko_serial_mcp --hub --host 127.0.0.1 --http-port 8080

# Codex 配置
# command = "/path/to/umeko_serial_mcp/.venv/bin/start-serial-mcp"
# env SERIAL_MCP_HUB = "http://127.0.0.1:8080"
```

串口名多为 `/dev/ttyUSB0`、`/dev/cu.usbserial-*` 等。  
开机自启用 `systemd` user service 或 `launchd`，将 `ExecStart` 指向上面的 `--hub` 命令即可。

## 11. 部署检查清单

- [ ] `pip install -e .` 成功  
- [ ] `start-hub` 后 `/api/health` 为 ok  
- [ ] 浏览器 WebSocket 显示已连接  
- [ ] 网页能列出并连接 COM  
- [ ] Codex `hub_status` 成功  
- [ ] 网页发送后，Codex `read_data` 能看到 `[用户/网页]`  
- [ ] Codex `write_data` 后，网页出现 `[AI Agent 发出]`  
- [ ] 下位机回传两边都能看到  

全部勾选即部署完成。
